# medrush
MedRush — a voice-controlled healthcare super-app UI prototype (HTML/CSS/JS) with telemedicine, medicine ordering, emergency SOS, and family health features.

MedRush is a single-file, front-end prototype of a comprehensive healthcare app, built as an interactive phone-frame mockup in pure HTML/CSS/JavaScript. It demonstrates a full user journey — from language selection and login (phone, email, location) through a rich set of health services, including:

Video consultations with doctors
Medicine ordering and Jan Aushadhi pharmacy locator
Emergency SOS and one-tap emergency assistance
Specialist and veterinary doctor directories
Blood donor directory
Family Emergency Circle for shared safety alerts
Digital Medical ID
First Aid guide
Nearby hospital/facility finder (Leaflet.js maps)
AI medical assistant chat
Voice control (Alexa-style) navigation across the app

The whole experience runs client-side with a custom view-routing system (goTo()), no backend required — ideal for demos, design reviews, or as a starting point for a real implementation.
